Add missing HTML attributes from the HTML Standard

Adds 17 attributes that are defined in the WHATWG HTML Standard but were
missing from the HTML data, so VS Code did not offer completions, value
completions or hovers for them:

- <area referrerpolicy>
- <button command>, <button commandfor> (invoker commands)
- <form rel>
- <iframe loading>
- <link disabled>, <link fetchpriority>, <link imagesizes>, <link imagesrcset>
- <script fetchpriority>
- <source width>, <source height>
- <template shadowrootmode>, <template shadowrootclonable>,
  <template shadowrootdelegatesfocus>, <template shadowrootserializable>
  (declarative shadow DOM)
- <video playsinline>

All are Baseline except <template shadowrootserializable> and
<video playsinline>, which ship in Chromium and WebKit and are marked
"Limited availability" by the generated data.

New value sets: `command` (show-modal, close, request-close,
show-popover, hide-popover, toggle-popover) and `shadowrootmode`
(open, closed). The `loading` value set descriptions now say
"resource" instead of "image" because <iframe> shares the set.

Regenerated data/browsers.html-data.json with `node html/generateData.mjs`.
