Web Spec Additions (HTML & CSS)

VS Code's HTML and CSS IntelliSense comes from built-in data that lags behind the specs. This extension adds HTML and CSS features that are in current web specs but missing from that data: completions, value completions, hovers with browser support and Baseline status, and no false "Unknown property" or "Unknown at rule" warnings.

  • Works in every window, with or without a folder open. The CSS data also applies to SCSS and Less.
  • Fills in hover text for built-in CSS properties that VS Code ships with an empty description.
  • Each item is also sent upstream as a PR. Once VS Code ships an item, the next build of the extension drops it.

Download

Visual Studio Marketplace: arronei.web-spec-additions. Search for it in the Extensions view, or run code --install-extension arronei.web-spec-additions.

Download web-spec-additions.vsix

Or download the .vsix, built from the latest commit, and install it either way, then reload the window:

  • In VS Code: open the Extensions view, choose ⋯ → Install from VSIX… and pick the downloaded file.
  • From a terminal:
code --install-extension web-spec-additions.vsix --force

Remove any html.customData or css.customData settings you added by hand for the same features, or completions show twice.

Settings

Choose which features the extension adds, by how established they are. Each level includes the ones above it. Changes apply after a window reload.

Reports

The HTML and CSS tabs list what VS Code's built-in data doesn't have yet, from the latest gap report. P1: ships in Chrome, Edge, Firefox and Safari. P2: ships in one to three of them. P3: not shipping, deprecated or non-standard.

Data: w3c/webref, browser-specs, @mdn/browser-compat-data, web-features and mdn-data.
